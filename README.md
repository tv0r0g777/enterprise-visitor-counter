# Система анализа и учёта посещения предприятия

## О проекте

Данный проект разработан в рамках технологической практики по специальности **«Искусственный интеллект»**.

### Тема индивидуального задания

**«Анализ и учёт посещения предприятия с использованием возможностей нейронных сетей и системы видеонаблюдения»**

Цель проекта — разработка программной системы, позволяющей автоматически обнаруживать людей в видеопотоке, отслеживать направление их движения и вести учёт количества входов и выходов на территорию предприятия.

Для обнаружения людей используется нейросетевая модель **YOLO11n**, а для отслеживания обнаруженных объектов между последовательными кадрами применяется алгоритм **ByteTrack**.

Разработанная программа представляет собой прототип системы компьютерного зрения, предназначенной для автоматизации анализа посещаемости предприятия с использованием существующих или специально установленных камер видеонаблюдения.

---

## Основные возможности программы

Программа поддерживает следующие функции:

- анализ изображения с веб-камеры в реальном времени;
- обработка предварительно записанных видеофайлов;
- обнаружение людей с помощью нейросетевой модели YOLO11n;
- отслеживание обнаруженных людей с помощью ByteTrack;
- присвоение каждому обнаруженному человеку уникального Track ID;
- определение направления движения человека;
- фиксация факта входа на предприятие;
- фиксация факта выхода с территории предприятия;
- подсчёт количества вошедших людей;
- подсчёт количества вышедших людей;
- определение текущего количества людей на территории;
- отображение результатов непосредственно поверх видеопотока;
- ведение журнала зарегистрированных событий;
- сохранение событий в локальную базу данных SQLite;
- экспорт журнала посещений в CSV;
- виртуальный симулятор проходной;
- автоматизированное тестирование системы;
- расчёт Precision, Recall и F1-score;
- расчёт точности подсчёта;
- просмотр почасовой аналитики посещаемости.

# Нейросетевая модель

## YOLO11n

В программе используется нейросетевая модель:

**YOLO11n (`yolo11n.pt`)**

Модель применяется непосредственно в исходном коде программы для обнаружения объектов класса:

```text
person
```

В наборе данных COCO класс `person` имеет идентификатор:

```text
0
```

Поэтому при обработке видеопотока программа выполняет обнаружение только объектов класса `person`.

Это позволяет исключить из результатов другие объекты, которые нейронная сеть также способна обнаруживать, например автомобили, мебель, животных и другие категории.

---

## Порог уверенности нейросети

Минимальный порог уверенности модели установлен на уровне:

```text
0.35
```

То есть результат обнаружения учитывается только в том случае, если уверенность нейросетевой модели составляет не менее 35 %.

Данное значение было выбрано для обеспечения баланса между количеством корректных обнаружений и возможностью распознавания человека при разных условиях изображения.

---

## Реальный вызов YOLO11n в программе

Обработка каждого кадра выполняется с помощью реального вызова модели YOLO11n:

```python
results = self.model.track(
    frame,
    persist=True,
    tracker="bytetrack.yaml",
    classes=[PERSON_CLASS_ID],
    conf=CONFIDENCE,
    verbose=False
)
```

При этом:

- `frame` — текущий кадр видеопотока;
- `persist=True` — сохраняет информацию о треках между последовательными кадрами;
- `tracker="bytetrack.yaml"` — подключает алгоритм ByteTrack;
- `classes=[PERSON_CLASS_ID]` — ограничивает обнаружение классом `person`;
- `conf=CONFIDENCE` — задаёт минимальный уровень уверенности обнаружения;
- `verbose=False` — отключает лишний вывод информации в консоль.

Таким образом, нейронная сеть является непосредственной частью алгоритма работы программы и реально используется при обработке изображения.

# Отслеживание людей

## ByteTrack

После обнаружения человека нейронной сетью YOLO11n необходимо определить, является ли обнаруженный объект новым человеком или уже присутствовал на предыдущих кадрах.

Для этой задачи применяется алгоритм многокадрового отслеживания **ByteTrack**.

ByteTrack позволяет присвоить обнаруженному человеку уникальный идентификатор.

Например:

```text
Кадр 1 → Person #4
Кадр 2 → Person #4
Кадр 3 → Person #4
Кадр 4 → Person #4
```

Благодаря сохранению Track ID система понимает, что на последовательных кадрах находится один и тот же человек.

Это необходимо для анализа траектории его движения и предотвращения многократного подсчёта одного посетителя.

# Контрольная линия

Для определения входа и выхода в видеопотоке используется виртуальная контрольная линия.

В разработанной программе линия располагается на уровне:

```text
55 % высоты изображения
```

Положение линии задаётся параметром:

```python
LINE_POSITION = 0.55
```

Также используется защитная зона:

```python
LINE_MARGIN = 18
```

Она необходима для предотвращения повторной регистрации события при небольших колебаниях координат обнаруженного объекта возле линии.

---

# Определение направления движения

После получения координат обнаруженного человека вычисляется центральная точка его ограничивающей рамки.

На основе положения центральной точки относительно контрольной линии определяется направление движения.

Используется следующая логика:

```text
Движение сверху вниз → ВХОД

Движение снизу вверх → ВЫХОД
```

Если человек находился выше контрольной линии, а затем оказался ниже неё, система регистрирует событие:

```text
ВХОД
```

Если человек находился ниже контрольной линии, а затем оказался выше неё, регистрируется:

```text
ВЫХОД
```

После регистрации событие добавляется в журнал посещений и сохраняется в базе данных.

# Поддерживаемые источники видеоданных

Программа поддерживает три основных режима работы.

## 1. Веб-камера

В данном режиме программа получает изображение непосредственно с подключённой камеры.

Обработка выполняется практически в реальном времени.

Последовательность работы:

```text
Веб-камера
    ↓
Получение кадра
    ↓
YOLO11n
    ↓
Обнаружение person
    ↓
ByteTrack
    ↓
Определение Track ID
    ↓
Анализ пересечения линии
    ↓
Регистрация ВХОД / ВЫХОД
```

---

## 2. Видеофайл

В качестве источника можно выбрать предварительно записанный видеофайл.

Поддерживаются основные форматы:

```text
MP4
AVI
MOV
MKV
```

Данный режим позволяет проводить тестирование системы на заранее подготовленных видеозаписях.

---

## 3. Виртуальная проходная

Для демонстрации работы системы без доступа к реальной камере предприятия был разработан отдельный режим виртуальной проходной.

В нём создаётся искусственная сцена, имитирующая вход на предприятие.

Пользователь может:

- добавить входящего человека;
- добавить выходящего человека;
- добавить группу людей;
- провести автоматизированный тест.

Для создания виртуального посетителя используется выбранная пользователем фотография человека.

# Принцип работы виртуального стенда

Очень важной особенностью программы является то, что кнопки симулятора не изменяют статистику напрямую.

Например, нажатие кнопки:

```text
+ Входящий
```

не приводит к непосредственному увеличению счётчика.

Вместо этого выполняется следующая последовательность:

```text
Создание виртуального человека
        ↓
Движение человека по сцене
        ↓
Формирование последовательности кадров
        ↓
Передача кадров в YOLO11n
        ↓
Обнаружение объекта person
        ↓
Отслеживание через ByteTrack
        ↓
Получение Track ID
        ↓
Пересечение контрольной линии
        ↓
Регистрация события ВХОД
        ↓
Изменение статистики
```

Таким образом, даже виртуальный режим проходит через ту же нейросетевую обработку, которая используется для реального видеопотока.

# Метрики качества

Для оценки работы системы используются следующие показатели:

## Precision

Precision показывает долю правильно зарегистрированных событий среди всех событий, зарегистрированных системой.

Формула:

```text
Precision = TP / (TP + FP)
```

где:

- TP — количество правильных обнаружений;
- FP — количество ложных обнаружений.

---

## Recall

Recall показывает, какую долю реальных событий система смогла правильно зарегистрировать.

Формула:

```text
Recall = TP / (TP + FN)
```

где:

- TP — количество правильных обнаружений;
- FN — количество пропущенных событий.

---

## F1-score

F1-score представляет собой гармоническое среднее Precision и Recall.

Формула:

```text
F1 = 2 × Precision × Recall / (Precision + Recall)
```

---

## Точность подсчёта

Дополнительно рассчитывается точность определения количества входов и выходов.

Она позволяет оценить соответствие результата системы заранее известному тестовому сценарию.

# Конфиденциальность

Разработанная система не выполняет распознавание личности.

В программе отсутствует идентификация человека по:

- имени;
- лицу;
- документам;
- биометрическим данным.

Нейронная сеть определяет только наличие объекта класса:

```text
person
```

Track ID используется исключительно как временный технический идентификатор объекта в видеопотоке.

Например:

```text
Person #1
Person #2
Person #3
```

После прекращения отслеживания объекта Track ID не является информацией о личности человека.

# Назначение разработки

Проект демонстрирует возможность применения технологий искусственного интеллекта и компьютерного зрения для автоматизации учёта посещаемости предприятия.

Использование нейросетевой модели позволяет отказаться от ручного подсчёта посетителей и выполнять анализ видеопотока автоматически.

Разработанный прототип объединяет:

```text
нейронную сеть
+
компьютерное зрение
+
отслеживание объектов
+
базу данных
+
аналитику
```

в единую программную систему.
